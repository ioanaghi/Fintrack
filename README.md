# Fintrack

React Native financial-education prototype with lessons, quizzes, and game screens, created for Polihack.

## Purpose

A mobile learning prototype exploring financial education through lessons, quizzes, and game interfaces. Created as a team project for the Polihack competition.

## Repository layout

The application lives in `FinTrack-main/`. Feature screens are grouped under `App/Screens/` for authentication, lessons, quizzes, games, and the home flow.

## Run locally

```sh
git clone https://github.com/ioanaghi/Fintrack.git
cd Fintrack/FinTrack-main
npm install
npm start
```

Check `package.json` for the original Expo/React Native versions and use a compatible emulator/development client. Any external authentication services require separate development configuration. A clean installation has not yet been verified.

## Scope

Educational prototype, not financial advice or a financial-services platform. Lesson/quiz content and game UI do not provide banking or trading functionality. Use sample accounts and avoid real financial information in demonstrations.
